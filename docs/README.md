# Документация проекта

Платформа онлайн-курсов «Алексей Ларин». Эта папка — единственный источник правды по архитектуре и контракту между компонентами. **Перед любой задачей начни отсюда** (см. [CLAUDE.md](../CLAUDE.md)).

## Содержание

- [01-architecture.md](01-architecture.md) — обзор системы, сервисы, потоки данных, сети, хранилище.
- [02-database.md](02-database.md) — схема БД, индексы, миграции.
- [03-api.md](03-api.md) — все HTTP-эндпоинты, контракт, аутентификация, CSRF.
- [04-frontend.md](04-frontend.md) — структура Astro, страницы, middleware, защита роутов.
- [05-payments-video.md](05-payments-video.md) — интеграция с Продамусом и защищённая отдача видео.
- [06-testing.md](06-testing.md) — что покрыто тестами, как их запускать.
- [07-deploy-ops.md](07-deploy-ops.md) — деплой, бэкапы, переменные окружения, бэкап/восстановление.
- [08-glossary.md](08-glossary.md) — термины и сокращения.

## Quick links для разработчика

- Корень репо: монорепо (api/ + web/ + nginx/ + docker-compose.yml + Makefile).
- Поднять локально: `make up`. Прогнать тесты: `make test`. Полностью с нуля: `make fresh`.
- Креды seed-аккаунтов и quickstart — в корневом [README.md](../README.md).
